# Plan: Vibe Coding Manual (HTML5)

## 📌 Resumen
Manual de referencia y guía técnica sobre la metodología **Vibe Coding** (desarrollo ágil asistido por Inteligencia Artificial y agentes de programación). Construido como una aplicación web en HTML5 semántico, CSS3 moderno y JavaScript ES6+ sin dependencias externas.

## 🎯 Objetivos
- [x] Sintetizar patrones, flujos de trabajo, prompting declarativo y colaboración persona-IA para la filosofía "Vibe Coding".
- [x] Documentar mejores prácticas en arquitectura de prototipado rápido, refactorización asistida e integración de LLMs en el ciclo de vida del software.
- [x] Ofrecer interfaz responsive, tema claro/oscuro persistente, buscador y navegación tipo SPA.

---

## 🏗️ Arquitectura

- **Patrón**: SPA estática modular vanilla sin backend.

`	ext
vibe-coding-manual-html5/
├── index.html         # SPA principal con guía conceptual y práctica
├── css/
│   └── style.css      # Sistema de diseño HSL, temas claro/oscuro y componentes
├── js/
│   └── app.js         # Ruteo SPA, buscador, copia de prompts y almacenamiento local
├── README.md          # Documentación general
└── plan.md            # Plan de desarrollo y hoja de ruta
`

## 🧠 Paradigma de Programación

- **Híbrido: Declarativo + Event-Driven**
- Basado en componentes declarativos (UI) y manejo de eventos para la interacción, buscador y copia rápida.
